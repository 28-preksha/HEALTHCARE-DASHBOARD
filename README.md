# Healthcare Dashboard

A modern and responsive Healthcare Dashboard built with React, designed to help healthcare professionals monitor patients, manage appointments, and visualize hospital data efficiently.

## Features

- Hospital Overview Dashboard
- Patient Management System
- Appointment Scheduling & Tracking
- Interactive Charts and Analytics
- Department-wise Patient Statistics
- Search and Filter Functionality
- Dark / Light Mode Toggle
- Responsive User Interface

## Tech Stack

- React 18
- Recharts
- Lucide React Icons
- CSS3
- JavaScript

## Installation

```bash
npm install
npm start
```

The application will run at:

```bash
http://localhost:3000
```
